# Bin Reminder

> **⚠️ Project Status: Not Currently Maintained**
>
> This isn't currently in use so I have deactivated the infrastructure in the back end. I will probably reactivate and keep working on it, currently I have no wheely bins to be reminded about!

## About

This was an AWS Lambda function created in .NET which scraped a local council website to determine which bin collection was due, and sent automated reminders via WhatsApp.

## Historical Context

The project demonstrated automated web scraping and notification capabilities using:
- AWS Lambda for serverless execution
- .NET for the core application logic
- WhatsApp integration for notifications
- Web scraping to extract bin collection schedules from council websites
